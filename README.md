Lumina Learn 🚀

Lumina Learn is a modern, responsive, and feature-rich online learning platform designed to help students and professionals discover high-quality courses, inspect detailed syllabi, read verified student reviews, and track their learning progress seamlessly.

🌐 Live Demo: https://lavanyasaisri-max.github.io/Lumina-Learn/

✨ Key Features

Dynamic Course Catalog & Search: Instant keyword search across course titles, skills (e.g., React, Python, Figma), instructors, and free courses with instant result filtering.

Category & Skill-Level Filtering: Easily sort and filter courses by categories (Web Development, Data Science, UI/UX, etc.) and difficulty levels (Beginner, Intermediate, Advanced).

Comprehensive Course Detail Modal:

Overview & Outcomes: Clear bullet points of what students will learn.

Expandable Curriculum: Multi-module syllabus view with lesson durations and free preview tags.

Instructor Profiles: Backgrounds, ratings, and course counts for expert instructors.

Verified Reviews & Submissions: Star rating distribution bars and an interactive form to submit new student reviews.

Interactive "My Learning" Drawer: Slide-over drawer with real-time course completion progress bars and lesson advancement tracking, persisted via browser localStorage.

Responsive & Polished UI: Built with Tailwind CSS, featuring smooth modal animations, custom SVG graphics for every course, and clean typography.

🛠️ Tech Stack

HTML5 & JavaScript (ES6+)

Tailwind CSS (via CDN for rapid styling and responsive layout)

Google Fonts (Plus Jakarta Sans & Inter)

HTML5 LocalStorage API (for persisting student enrollments and progress)

🚀 Quick Start / Local Setup

Because Lumina Learn is built as a zero-build single-file application, running it locally requires no complex package manager installation.

Clone or Download this repository:

git clone https://github.com/lavanyasaisri-max/Lumina-Learn.git


Open the project folder and locate index.html.

Run the app:

Double-click index.html to open it directly in your web browser, OR

Open it using a local development server like Live Server in VS Code for live reloading.
